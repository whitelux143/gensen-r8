# 令和8年分 源泉所得税計算

令和8年分の給与等（月額）に係る源泉徴収税額を求めるWebツール。甲欄（電算機計算の特例）と乙欄（月額表）に対応する。

ビルド不要の単一HTMLファイルで構成されており、GitHub Pages にそのまま配置できる。

## 使い方

画面上部の「税額区分」で甲欄・乙欄を切り替える。初期値は甲欄。

| 区分 | 計算方法 |
|---|---|
| 甲欄（機械計算） | 月額表の甲欄を適用する給与等に対する源泉徴収税額の電算機計算の特例（別表第一〜別表第四） |
| 乙欄（月額表） | 令和8年分 給与所得の源泉徴収税額表（月額表）乙欄 |

給与等の支給額と社会保険料等は両区分で共通の入力欄であり、区分を切り替えても入力値は保持される。社会保険料等は健康保険料・厚生年金保険料・介護保険料・雇用保険料・その他の5項目に分けて入力し、合計額を支給額から控除する。

## 計算仕様

### 甲欄

社会保険料等控除後の給与等の金額から、給与所得控除・配偶者控除等・扶養控除等・基礎控除を控除して課税給与所得金額を求め、税率を適用する。端数処理は給与所得控除が1円未満切上げ、税額が10円未満四捨五入。

浮動小数点誤差を避けるため、税額はすべて1/100,000円単位の整数で保持している。

### 乙欄

社会保険料等控除後の給与等の金額を A として、次の3帯に分かれる。

| A の範囲 | 税額 |
|---|---|
| 105,000円未満 | A × 3.063%（1円未満切捨て） |
| 105,000円以上 740,000円未満 | 月額表乙欄の該当行（全231行） |
| 740,000円以上 1,710,000円未満 | 259,200円 ＋（A − 740,000円）× 40.84% |
| 1,710,000円以上 | 655,400円 ＋（A − 1,710,000円）× 45.945% |

甲欄と異なり、乙欄には 790,000円・960,000円・2,130,000円・2,170,000円・2,210,000円・2,250,000円・3,500,000円における税率の切替が存在しない。税額表の乙欄は該当範囲が縦方向に結合されており、基準額は 740,000円 または 1,710,000円 のまま変化しない。

「従たる給与についての扶養控除等申告書」の提出がある場合、上記により求めた税額から扶養親族等1人につき1,610円を控除する。控除後の税額は0円を下限とする。

### 端数処理に関する注記

740,000円以上の計算式帯における端数処理は、税額表に明示的な定めがない。本ツールでは乙欄の他の帯（105,000円未満の3.063%）の取扱いに揃えて1円未満切捨てとしている。

また、A = 1,709,999円 の税額は 655,347円、A = 1,710,000円 の税額は 655,400円 であり、両者の間に53円の段差が生じる。これは税額表に 1,710,000円 の乙欄税額として 655,400円 が直接印字されていることによるもので、税額表どおりの挙動である。

## 検証

- 乙欄の税額表データ全231行について、国税庁「令和8年分 源泉徴収税額表」PDFから機械抽出した値と完全一致することを確認済み
- 行の連続性（前行の「未満」＝次行の「以上」）に切れ目がないことを確認済み
- 指示された境界値32点を含む64項目のテストに合格
- 甲欄については、改修前のコードと108,300通りの入力で突合し、税額および中間項目のすべてが一致することを確認済み

## 令和9年分への更新

`index.html` 内の `===OTSU-DATA-START===` から `===OTSU-DATA-END===` までのブロックを差し替えることで対応できる。更新対象は次の4つ。

| 定数 | 内容 |
|---|---|
| `OTSU_TABLE` | 月額表乙欄の `[金額（以上）, 税額]` の配列 |
| `OTSU_FORMULA` | 高額帯の `{ base, tax, rate }` |
| `OTSU_LOW_RATE` | 105,000円未満に適用する率 |
| `OTSU_DEP_DEDUCTION` | 従たる給与の扶養親族等1人あたり控除額 |

甲欄の計算ロジックは `===CALC-START===` から `===CALC-END===` までのブロックに分離されている。

## 免責

本ツールは源泉徴収税額の確認用であり、税額には復興特別所得税相当額が含まれる。最終確認は国税庁の源泉徴収税額表等により行うこと。
